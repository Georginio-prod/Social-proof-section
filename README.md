## 📌 Présentation

Section de **preuve sociale** : titre accrocheur, trois notes « Rated 5 Stars » (Reviews, Report Guru, BestTech) décalées en escalier et trois cartes de témoignages elles aussi décalées verticalement sur desktop.

Réalisé en **HTML sémantique + Sass**, servi par **Vite** (rechargement à chaud et build optimisé),
sans framework JavaScript : l'objectif est la maîtrise du CSS et du responsive.

## ✨ Fonctionnalités

- Cartes de notation avec étoiles, décalées horizontalement sur desktop.
- Cartes de témoignages (avatar, nom, badge « Verified Buyer », texte) décalées verticalement.
- Fonds décoratifs en haut à gauche et bas à droite.
- Empilement vertical simple sur mobile.

## 📁 Structure

```
Social-proof-section/
├── index.html              # Toute la structure de la page
├── sass/style.scss         # Feuille de style SCSS (variables, imbrication, media queries)
├── main.js                 # Importe le SCSS (point d'entrée Vite)
├── public/                 # Images, icônes, fonds de la maquette
└── package.json
```

## 🚀 Installation & lancement

```bash
git clone https://github.com/Georginio-prod/Social-proof-section.git
cd Social-proof-section
npm install
npm run dev          # http://localhost:5173
```

`npm run build` génère le site statique dans `dist/` ; `npm run preview` le prévisualise.

## 🌐 Déploiement

Déployé sur **Vercel** (framework Vite, sortie `dist/`). Aucune variable d'environnement.

## 🎓 Ce que ce projet démontre

Décalages avec `transform` / marges, Flexbox et Grid combinés, police League Spartan.
